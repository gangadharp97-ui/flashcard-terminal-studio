# 🗂️ Flashcard Learning Engine
### Desktop GUI Application & Structured Relational SQLite Architecture

An object-oriented desktop application built to create, manage, and execute study deck tracks. This system couples a clean, user-friendly client interface with a resilient relational database tier to persist historical study performance and data parameters across active user sessions.

🔗 **[Live Interactive System Previewer](https://gangadharp97-ui.github.io/flashcard-terminal-studio-project/)**

---

## 🏗️ Architecture Features
* **Encapsulated Client Layer:** Leverages Python's structural interface models to control layout grids, stateful toggle buttons, and dynamic display changes cleanly.
* **Persistent Relational Engine:** Direct connection pooling interfaces link straight to a local SQLite asset tracking storage layer.
* **Algorithmic Review Architecture:** Includes built-in data attributes (`review_count`, `ease_factor`) to support system logic for learning cycles and algorithmic retention filters.
